# Archived code

This directory contains historical research workflows that are no longer part
of the supported Milky Way halo pipeline.  They are retained for provenance and
for reconstructing earlier modelling decisions, not as importable application
code.

Active code, tests, configurations, and interactive analysis must not import
from `archive/`.  Archived scripts are not installed by the package, are not
covered by the production test suite, and may require unavailable data,
obsolete dependencies, or an older Python environment.

The first snapshot is [`legacy_workflows/`](legacy_workflows/README.md).  Its
README records the source revision, original layout, dependency assumptions,
known gaps, and syntax failures.  Generated models, catalogues, figures,
private research notes, and copyrighted papers are intentionally not copied
into the archive.
