# Zhu 经验轨道模型的 phi 分箱扩展

## 1. 不变的部分：经验轨道叠加

对每个 6D 观测相点，在候选势中积分轨道，并在时间上均匀采样。
若第 `i` 个种子星的代表性权重为 `w_i`，其每个轨道样本继承该权重；
在构造密度时再除以所采用的轨道样本归一化常数。这个常数只改变模型
总幅度，不改变形状。

本分支仍使用输入目录中的 `w` 作为轨道代表性权重，没有重新估计选择函数。

## 2. 从轴对称网格到 `(R,z,phi)` 网格

旧实现把所有方位角累加，只比较 `nu(R,z)`。新实现使用完整网格

```text
(R_i, R_{i+1}) × (z_j, z_{j+1}) × (phi_k, phi_{k+1})
```

其精确体积为

```text
V_ijk = 1/2 (R_{i+1}^2 - R_i^2)
        (z_{j+1} - z_j)
        (phi_{k+1} - phi_k).
```

因此模型密度为落入该格的加权轨道质量除以 `V_ijk`。旧 `4phi`
原型只除以 `R Δphi`，漏掉了 `ΔR Δz`；等宽网格下这只是共同常数，
但显式体积公式能支持不等宽网格并保持单位正确。

phi 被当作周期变量。核心代码统一把它包裹到
`[phi_edges[0], phi_edges[0] + 2π)`，避免 `-π/π` 边界重复或丢星。

## 3. 为什么只能使用一个全局幅度

模型轨道库的总幅度可能与观测密度的归一化不同，因此沿用原方法拟合尺度
`A`。默认的体积归一化为

```text
A = sum(data_ijk V_ijk) / sum(model_ijk V_ijk),
```

求和同时跨越所有 phi bin。随后

```text
chi2_k = sum_ij [(data_ijk - A model_ijk) / sigma_ijk]^2,
chi2_density = sum_k chi2_k.
```

不能给每个 phi bin 单独拟合 `A_k`。否则真实的方位角过密/欠密会被
各自的归一化吸收，结果会退化成“只比较每个扇区内部的形状”，无法约束
非轴对称势。

输出的 `sample.dat` 同时保存总 chi-square 和每个 phi bin 的
`chi2_phi*`，便于识别某一扇区的选择效应或模型失配。

## 4. 速度项

速度直方图现在具有轴序 `(r, theta, phi, v)`，并在每个空间格内归一化为
条件概率质量 `p(v | r,theta,phi)`。对观测星 `a`，用其速度误差与模型
直方图卷积：

```text
L_a = sum_l p_l Normal(v_a | v_l, sigma_a).
```

代码使用自然对数并分别累计每个 phi bin 的贡献。空的模型空间格不会发生
除零；若该格含有观测星，则使用概率下限给予模型惩罚，避免“模型少覆盖
一些数据反而得到更高似然”的偏差。内区轨道库本身不完整的问题仍由径向
边界排除。

## 5. 默认边界与限制

- 密度默认使用 `R,z = 0..50 kpc` 的 `25×25` 网格和 4 个等宽 phi bin。
- 默认只覆盖 `z>0`，与现有北天轨道种子和密度产品一致。
- 密度拟合区保留旧设置：`|z|>=2 kpc` 且 `15<=r<40 kpc`。
- 模型幅度默认在 `r>=10 kpc` 的所有有效 phi bin 上共同确定。
- 非 4-bin 实验必须重新生成匹配边界的观测密度文件。
- 当前 AGAMA `Spheroid` 势与坐标轴对齐；非零 halo 旋转角会明确报错，
  不再像旧代码一样被静默忽略。
