# Zhu 经验轨道模型的 phi 分箱扩展

## 1. 不变的部分：经验轨道叠加

主流程直接读取北半球种子星表 `halo_clean_N.txt` 已提供的选择函数校正权重：

```text
w_i = halo_clean_N.txt["w"]_i.
```

这一组权重在候选势优化开始前只计算一次，不随势参数变化。

随后对每个 6D 观测相点，在候选势中积分轨道，并在时间上均匀采样。
第 `i` 个种子星的每个轨道样本继承相同的固定 `w_i`；
在构造密度时再除以所采用的轨道样本归一化常数。这个常数只改变模型
总幅度，不改变形状。

密度和三个速度直方图使用完全相同的逐轨道权重。观测速度似然仍然逐星
等权累计，不再额外乘 `w_i`，从而避免重复进行选择函数校正。这仍然是
Zhu/legacy 式固定经验权重方法，不包含传统 Schwarzschild `A w = d`
的内层非负权重求解。

`nu_target(R,z,phi)` 与误差文件只作为密度检验目标，不参与生成轨道权重。
从三维目标密度反推 `w_i = nu_target[j] V[j] / N_seed[j]` 的函数保留为
独立实验工具，不进入正式优化路径。

## 2. 从轴对称网格到 `(R,z,phi)` 网格

旧实现把所有方位角累加，只比较 `nu(R,z)`。新实现使用完整网格

```text
(R_i, R_{i+1}) × (z_j, z_{j+1}) × (phi_k, phi_{k+1})
```

其精确体积为

```text
V_ijk = 1/2 (R_{i+1}^2 - R_i^2)
        (z_{j+1} - z_j)
        (phi_{k+1} - phi_k).
```

因此模型密度为落入该格的加权轨道质量除以 `V_ijk`。旧 `4phi`
原型只除以 `R Δphi`，漏掉了 `ΔR Δz`；等宽网格下这只是共同常数，
但显式体积公式能支持不等宽网格并保持单位正确。

phi 被当作周期变量。核心代码统一把它包裹到
`[phi_edges[0], phi_edges[0] + 2π)`，避免 `-π/π` 边界重复或丢星。

## 3. 为什么只能使用一个全局幅度

模型轨道库的总幅度可能与观测密度的归一化不同，因此沿用原方法拟合尺度
`A`。默认的体积归一化为

```text
A = sum(target_ijk V_ijk) / sum(model_ijk V_ijk),
```

求和同时跨越所有 phi bin。随后

```text
chi2_k = sum_ij [(target_ijk - A model_ijk) / sigma_ijk]^2,
chi2_density = sum_k chi2_k.
```

不能给每个 phi bin 单独拟合 `A_k`。否则真实的方位角过密/欠密会被
各自的归一化吸收，结果会退化成“只比较每个扇区内部的形状”，无法约束
非轴对称势。

输出的 `sample.dat` 同时保存总 chi-square 和每个 phi bin 的
`chi2_phi*`，便于识别某一扇区的选择效应或模型失配。

## 4. 速度项

速度直方图现在具有轴序 `(r, theta, phi, v)`，并在每个空间格内归一化为
条件概率质量 `p(v | r,theta,phi)`。对观测星 `a`，用其速度误差与模型
直方图卷积：

```text
L_a = sum_l p_l Normal(v_a | v_l, sigma_a).
```

代码使用自然对数并分别累计每个 phi bin 的贡献，只让 `r>=8 kpc` 的恒星
进入速度似然，以恢复论文和 legacy 对不完整内区轨道库的排除。空的模型空间格不会发生
除零；若该格含有观测星，则使用概率下限给予模型惩罚，避免“模型少覆盖
一些数据反而得到更高似然”的偏差。

## 5. 与新增维度配套的图像诊断

原论文 Fig. 6 的二维 `(R,z)` 密度图现在有两种输出：一个以 phi bin
为列的总览（首列额外保留 phi 平均基准），以及每个 phi bin 一张的四面板图。后者同时显示 target、
model、target 的相对误差和标准化残差，并使用全局统一的密度色标，避免
每个方位扇区单独拉伸色标后掩盖真实的方位差异。

扁率诊断不先对 phi 平均。对每个 phi slice，代码分别在最低 z 和最低 R
网格线上求等密度面的主轴截距 `R_iso` 和次轴截距 `z_iso`，并绘制
`q_star=z_iso/R_iso` 随 `R_iso` 的变化。稀疏经验密度可能不严格单调，
所以插值前只施加“由中心向外非增”的包络；该图是模型诊断量，不进入似然。

原论文 Fig. 7 的速度阵列也按 phi 分页。每页仍以半径为行、theta 为列组，
并并排展示三个速度分量。灰色虚线是按每格观测星数计算的多项分布
1-sigma 计数不确定度；红线为该 trial 的固定权重轨道模型。每个子图标出
实际观测星数，空数据格保持可见但不伪造观测曲线。另输出一个以每个
空间格占据数加权合并 phi 的基准页，用于与原论文图直接比较；它不是对
各 phi 条件概率作简单算术平均。

## 6. 默认边界与限制

- 密度默认使用 `R,z = 0..50 kpc` 的 `25×25` 网格和 4 个等宽 phi bin。
- 默认只覆盖 `z>0`，与现有北天轨道种子和密度产品一致。
- 密度拟合区保留旧设置：`|z|>=2 kpc` 且 `15<=r<40 kpc`。
- 模型幅度默认在 `r>=10 kpc` 的所有有效 phi bin 上共同确定。
- 非 4-bin 实验必须重新生成匹配边界的观测密度文件。
- 轨道权重来自 `halo_clean_N.txt["w"]`，并在全部候选势中固定。
- `nu_target(R,z,phi)` 和误差只用于密度验证，与权重来源分离。
- `fixed_seed_weights.npz` 保存逐星权重、格内权重和、有效样本数和最大权重
  占比，供检查少数大权重恒星或轨道是否主导某个 phi 格。
- 速度直方图仍保留 `4<r<8 kpc` 用于诊断，但这一区域不进入速度似然。
- 当前 AGAMA `Spheroid` 势与坐标轴对齐；非零 halo 旋转角会明确报错，
  不再像旧代码一样被静默忽略。
