# nphi1 分束实验修复与复核方案

状态：2026-09-14，方案已编写，尚未实施或重跑实验。

目标：修复随机映射、密度评分、计时和诊断问题，获得可以复核的同点比较；随后才判断是否值得做三势点排序检验。编写本方案不代表已授权执行新的积分或参数扫描。

沿用 [权重模型契约](density_solved_weights.md)、[项目蓝图](project_blueprint.md) 和 [扁平架构](architecture.md)。[solver-budget 方案](solver_budget_experiment.md) 提供参考资格、预测误差和排序检验的方法，但它的 r8–40、显式 phi、joint objective 实验与本 nphi1 实验不同，不能混用验收结论。

### 2.1 统一权重后的评分

在 `evaluate.py` 提取一个领域函数，例如：

```python
score_orbit_weights(library, prepared, weight_solution, response=None)
```

沿用已有WeightSolution和ModelEvaluation，不新建类型。生产 `evaluate_orbit_library` 完成原来的求解后调用它；实验三种方法把各自解与诊断组装成同一已有对象后调用它。外部缓存和数组检查放在输入边界一次完成。

共享函数按原有顺序执行：

1. 使用solution中的归一化target/error、原始model density，以及完整density_fit配置；density_solved明确scale=1。
2. 通过response的映射与每轨道有限样本数生成sample weights。
3. 执行支持审计和原始201-bin速度评分；使用相同相空间转换。
4. 生成现有ModelEvaluation，由现有属性计算raw velocity J、joint J、密度门槛和selected J。

不能在脚本里另写 `chi2/bin <= 2` 代替整个验收；必须保留solver失败时的惩罚路径、配置中已有的shell规则和非有限值处理。不得改变catalogue_fixed分支的权重或评分语义。

最小归一化oracle：target=1、error=0.1、model=2时，固定scale评分应为每bin chi2=100；不得因隐式scale=0.5变成0。真实数据上的评分应与直接计算

```text
sum_mask [ (rho_model - target/M) / (error/M) ]²
```

一致，其中M只在配置的density fit mask上计算。

### 2.2 随机映射与分束方程

设A为已经除以误差的active-orbit设计矩阵，b为对应观测，S为0/1成员矩阵，w=S u。分束实际求解：

```text
min(u >= 0) ||A S u - b||² + lambda * sum_k(n_k * u_k²)
```

`A @ S`使用成员列之和，正则对角项为`sqrt(lambda*n_k)`。不把列换成均值而仍沿用同一权重解释。

```python
random_assignments = rng.permutation(assignments)
random_counts = np.bincount(random_assignments, minlength=bundle_count)
u_random = solve_bundled(A, b, random_assignments, random_counts, regularization_strength=1e-6)
w_random = u_random[random_assignments]
```

实际函数签名在实施时与脚本保持一致。保存两套assignments和成员数，验证物理组与随机组的成员数一致。回填顺序必须遵循active列→successful seed→完整seed，不能假定seed编号连续、已排序或无失败。

验收恒等式：`A @ w == (A @ S) @ u`，且 `lambda*dot(w,w) == lambda*sum(n*u*u)`，rtol=atol=1e-12。测试包含不等束大小、空束、打乱的seed编号和零响应列；空束去除或固定零，不让不可识别的空束权重进入统计。

### 2.3 区分分束收敛与原始问题收敛

full继续执行历史lsq_linear接受规则并记录full-space KKT，不悄悄提高生产默认要求。分束NNLS对缩减变量u的问题判断收敛，并保存：

- NNLS正常结束、有限非负权重、正总质量；reduced-space KKT及所用归一化定义。
- 原始A、b上的full-space KKT，作为近似程度诊断。
- 原始内层目标F、密度项、正则项，不能把二者混在J中。

reduced KKT的拟议数值门槛为1e-8，运行前写入配置；不根据结果临时放宽。计算可直接使用增广矩阵`B=[A S; sqrt(lambda*n)]`和`y=[b;0]`的非负最小二乘KKT，沿用现有归一化约定。

分束在其约束子空间收敛，并不说明达到原始逐轨道NNLS最优解。报告需明确标注“受限分束近似”；其selected J通过共享门槛也不构成替换正式solver的批准。不要伪装成生产`dense_nnls`的全空间收敛结果。NNLS未提供的迭代数在实验JSON中标为null，不能声称为零次迭代。

### 2.4 公平计时

计时定义在运行前固定，两方法采用相同范围：

| 时间 | 包含内容 |
| --- | --- |
| input/cache | 配置、输入准备、缓存读取与校验 |
| response | 由轨道样本构建nphi1响应 |
| grouping | 计算E、lambda_z、轨道汇总及分位数assignments |
| matrix | 原始归一化设计矩阵、分束列聚合、增广矩阵构建 |
| solve | 仅backend求解调用；两边都从矩阵就绪时开始 |
| reconstruct | 回填seed权重、模型密度、solution诊断 |
| score | 坐标转换、支持审计、速度评分、正式objective |
| write/plot | 分别记录，不计入数值评估加速比 |

另以外层计时器直接测量完整冻结库数值评估，并与分项求和核对，防止遗漏。bundled完整成本必须包含grouping；为random复用物理组的成员规模时，明确其共享前处理成本。

首次结果只报告“单次测量”。如需稳定速度比，在相同已冻结输入上以独立进程交替跑三次full/bundled，全部cold start；记录每次、中位数和范围。输入读取、绘图不能只在某一种方法中计入。无缓存端到端耗时必须真实测量，不能把solve-only时间称作iteration耗时。

## 四、实施与验收顺序

### 阶段0：冻结证据和输入（只读）

检查两端Git状态，保留现有未提交修改和服务器未跟踪nphi1配置。在独立工作区实施；旧结果目录保持原样。保存旧脚本、JSON、目标和缓存哈希、精确参数及运行环境。删除新脚本中硬编码的production J；引用实际metadata，并先验证可比性。

旧缓存未保存的来源不能事后补写成已验证事实。它仍可用于“同一给定缓存内”的纠错对照，但不能据此声称生产端到端parity。

**退出条件：** 三个case的输入边界明确，旧实验可追溯，新attempt路径不存在。

### 阶段1：本地实现和小数组验收（不积分）

按第二、三节实现共享评分、映射和产物绘图。必须通过：

| 检查 | 判定 |
| --- | --- |
| 生产评分提取前后parity | 相同权重/库/配置，状态一致，浮点rtol=atol=1e-12；fixed与density_solved均覆盖 |
| 随机映射与正则oracle | 两个恒等式成立；错误映射的负例必失败 |
| 振幅oracle | scale=1，不能通过重新归一化消除振幅错误 |
| 正式拒绝路径 | 密度超限、solver失败仍产生现有惩罚；raw J单独保留 |
| support/采样 | 零密度支持轨道、每轨道不同有限样本数、失败seed映射不被漏掉 |
| 产物与图 | 复读重算标量一致；绘图不导入或调用积分/solver；非方形网格方向正确 |

用`conda run -n dp-jax python`执行相关测试；完成共享生产代码修改后跑完整unittest与compileall。缺依赖的跳过明确记录，并在halo_lmc补测，不安装或切换环境凑通过。

**退出条件：** 上述回归通过，未改变生产评分结果；修复提交与本地研究材料分离。

### 阶段2：同一冻结点纠错（不重新积分）

在服务器halo_lmc中运行full、bundled、random，使用真实nphi1 target和同一库/响应。分组用该库实际建势参数；不得为了贴近生产舍入点而只改变分组的势、仍保留旧库。

三种方法均共享正确评分，保留成功和失败case。检查scale=1、权重有限非负、总质量正、零失败轨道、公式oracle及产物可复读。用保存的数组独立重算chi2、J和门槛；门槛不通过是有效科学结果，不以改阈值或换seed修饰。

重建真实target八面板图，并按公平口径报告时间。先做一次纠错比较；如单点方法有继续价值，再做固定库的三次重复计时，避免无价值重复。

**退出条件：** 结果可复核，明确每种方法的正确J、密度门槛和完整开销。此时允许的结论是“这个给定冻结库上的受限分束比较”，不包括生产替代或参数排序。

### 阶段3：对齐生产锚点与来源差异（需要重新积分）

阶段2完成并决定继续后，使用生产坐标解析路径，从相同三位小数optimizer向量得到物理参数。paper-best锚点为：

```text
(qhalo, phalo, rho0, rho0_plus_2logrs, gamma) = (0.920, 0.800, 6.200, 9.890, 1.000)
log_rs = (rho0_plus_2logrs - rho0)/2
```

不另用`log10(70)`替换解析结果。数值建势、分组坐标、记录和评分使用同一参数对象。

在新目录生成统一参数的新库。Python启动前固定BLAS=1、OMP=16并记录threadpoolctl实际值；不把OMP环境变量缺失解释为单线程。与生产路径做同一参数、同一准备数据的评分对照，优先捕获同一次生产积分返回的库用于冻结评分parity，避免把两次独立积分差异混入评分比较。

只有在还需要解释线程效应时，才做单因素对照：固定一切其他条件，在OMP=1和16下各独立积分至少两次，记录实际线程池、库/响应哈希、逐数组偏差和下游J；每个库的solver线程保持相同。分别比较组内重复与组间差异，不能从一个差值直接推断线程因果。哈希不一致时进一步看差异大小及传播，不将“不逐位相等”自动称为物理不稳定。

**退出条件：** 共享库评分parity达到1e-12；独立积分的重复性另行量化。无法隔离的来源差异明确列为未解决，不输出bit-for-bit承诺。

### 阶段4：三势点排序pilot（独立的后续实验）

进入条件：阶段1–3正确性证据完整；bundled在修复后的单点满足其数值终止和现有密度门槛，且计入grouping/score后仍有速度收益。未通过则停留在方法诊断，不自动扫更多点。

可以沿用solver-budget中的三个坐标，但accepted_best/capped_candidate只表示历史来源，在nphi1下不预设接受状态：

| 点 | qhalo | phalo | rho0 | rho0_plus_2logrs | gamma |
| --- | ---: | ---: | ---: | ---: | ---: |
| paper_best | 0.920 | 0.800 | 6.200 | 9.890 | 1.000 |
| accepted_best | 0.985 | 0.714 | 6.099 | 9.829 | 0.751 |
| capped_candidate | 1.071 | 0.738 | 5.687 | 9.541 | 1.214 |

此阶段开始前单独冻结nphi1验收设置：每点积分一次，同点full/bundled共用库；每点用自身势计算分组，保存assignments变化。每点报告

```text
delta_i = J_bundled(theta_i) - J_full(theta_i)
pair_error_ij = delta_i - delta_j
```

“排序相同”只是一项粗筛，还要报告绝对偏差和点对误差。拟议沿用solver-budget的严格数值近似标准作为单独标注的参考：abs(delta_i)≤1、abs(pair_error_ij)≤1；参考差值>2不得翻转，≤2只算近似并列；密度预测RMS≤0.01 sigma；每速度分量观测加权TV≤1e-3，观测数≥20的cell最大TV≤0.01。全部在原始201 bins上检查。

这些标准需在看新结果前写入实验配置。若只有排序保留、绝对分数偏移较大，应标为“存在偏移的排序近似候选”，不能宣称严格数值等价；其是否可用于优化器需要另定误差预算、留出点和密度门槛翻转风险检验，不减去事后拟合常量来制造通过。

full可先作“当前生产算法基线”；要称高精度参考，仍须满足solver-budget的full-space KKT≤1e-8与内层F sanity check，不合格时采用已存在的参考backend验证或停止判定。三点检验不等于全参数空间保证，不自动启动GP或大规模搜索。

## 七、诊断：random 的速度 J 优势来源（2026-09-15）

§六留下的模式需要一个机制定位。速度 J 是外层目标，内层 NNLS 从不看到它，因此"random 赢 J"的可能来源有四类：随机种子运气；等权约束子空间的方向本身；该子空间内密度重解选出的特定解；或约束强度（束数）恰好处于某机制区。诊断实验在 (λ_z,E) 32×32 的同一冻结库上用四个可分离检验逐一排查（`scripts/diagnose_random_j_advantage.py`）：

1. **种子稳健性**：8 个独立 random 种子（成员数分布不变），报告 ΔJ 分布与物理分组单值的关系；分布与物理值重叠则"random 赢"不成立。
2. **投影检验**：把 full 解按束成员均值投影到等权子空间（物理 assignments 与一个 random assignments 各一次），投影不做任何重解。若随机子空间投影的 J 已低于物理子空间投影，机制在子空间方向；若两者接近而重解后分岔，机制在求解。
3. **α 插值**：w(α) = (1−α)·w_full + α·w_投影，α∈{0,0.25,0.5,0.75,1}。J(α) 曲线的方向与曲率给出"向等权移动"对 J 的边际效应，按子空间分列。
4. **束数扫描**：8²、16²、32²、64² 的物理与 random（固定种子）并列，看 ΔJ 与有效轨道数随约束强度的走势，检验"欠约束恰好区"假说。

判读边界：全部是同一冻结库上的方法诊断，单次测量口径不变；不外推到生产或参数排序。产物目录 `.agent-local/benchmarks/nphi1_random_diagnosis/`。

结果（2026-09-15，全部 case 过共享评分、full 逐位复现 J=137320.278）：**(1) 种子稳健性**：8 个 random 种子的 ΔJ ∈ [−128.6, +441.2]、中位 +54，6/8 低于物理分组的 +183.4——倾向成立但单种子散布约 ±250，此前各阶段单 random 对照仅为弱证据。**(2) 投影**：full 解按束成员均值投影（不重解）后，物理方向 ΔJ=−35.2（chi2/bin 0.878，过门槛）、random 方向 ΔJ=−599.2（chi2/bin 13.96，**门槛失败**）；α 插值在两个方向都随平均程度单调降 J。**(3) 束数扫描**（64/256/1024/4096）：物理 +232.5/+735.2/+183.4/+407.0，random −367.7/−269.3/+64.6/+282.8，random 在低束数下过不了密度门槛（chi2 10.5/4.02）。**(4) 跨全部 29 个 case 的 Spearman(χ²/bin, ΔJ) = −0.694**（p=3e-5）。

机制结论：速度 J 是内层密度拟合从未见过的 held-out 目标；内层问题欠定（625 密度约束 vs 11250 权重、λ=1e-6），NNLS 选出的逐轨道权重"纹理"对 J 是净损害——任何方向的等权平均都单调降低 J。物理分组把相似轨道绑在一起、保留密度拟合所需结构，也就保留了纹理；random 混合等于更狠的权重平滑（密度更差、权重更集中），恰好落在 J 偏好的方向。"random 赢 J"因此不是分组的物理优点，而是"以密度拟合换权重平滑度"的权衡表现，且在生产语义下被密度门槛封死（random 方向的极端平滑 gate 失败）。附带观察：物理方向的 full 解投影以 ΔJ=−35 通过门槛，是唯一 J 优于 full 的 gate-passing case，量级在种子噪声内，仅作记录。

## 八、基准切换：网格相关诊断在 nphi4 上重做（2026-09-15）

nphi1 基准的由来：修复实验的对象是修复前审计（`.agent-local/benchmarks/solver_settings_sweep/`），该实验是 nphi1 轴对称化变体；§一固定其科学定义以保持"同一缓存内纠错"的可审计性，后续诊断沿用同一冻结库与口径。但生产密度对比是显式 (R,z,phi) 的 nphi4：2500 个密度约束（vs nphi1 的 625），速度条件分布按 4 个 phi 扇区边缘化。约束数改变零空间结构，§六的分束权衡与 §七的欠定机制结论不能默认迁移到生产网格，须在 nphi4 上重做验证。

范围：与密度网格相关的三族诊断重做——(λ_z,E) 阶段2式对照、二维基实验（(E,ω_z)、(Jr,Jz)）、random J 优势诊断。与网格无关的不重做：轨道不变量两轮探索只依赖冻结库与势，λ_z 堆积、守恒度排序、正交结构与频率基的结论对两个网格同样成立。同一冻结库直接服务两个网格（轨道库与密度网格无关；冻结缓存本身存储的就是 4 扇区响应矩阵 2500×11250）。两 recipe 的 solver/objective/门槛设置逐项相同（已核对，唯一差异 n_phi 与速度 phi 边缘）；run config 换 `configs/runs/density_solved_benchmark.toml`（同一 catalogue、4 扇区 target `desi_year1_kgiants_25x25x4.npz`）。nphi1 的历史参考 JSON 属于 nphi1 审计证据，nphi4 配置不携带，避免跨网格引用。

新配置：`configs/benchmarks/nphi4_bundling.toml`、`nphi4_bundling_2d_energy_omegaz.toml`、`nphi4_bundling_2d_jr_jz.toml`、`nphi4_random_diagnosis.toml`；产物 `.agent-local/benchmarks/nphi4_*`。判读边界同§六/§七：单冻结库方法诊断，不外推生产替代或参数排序。

结果（2026-09-15，重建响应 nnz=1123039 与冻结缓存存储的 4 扇区矩阵逐位一致）：**(1) 可行性反转**：nphi4 上 1024 束的全部基与 random 对照密度门槛失败（chi2/bin 3.41–4.76 vs 门槛 2.0；nphi1 同设置 0.014–0.30 全过）——"分束轻松过门槛"是轴对称网格约束更少后的人为现象。束数扫描显示 4096 束才过门槛（物理 1.36、random 1.29）。**(2) 可行点的 J 排序反转**：4096 束处物理 ΔJ=+926.0 优于 random +1080.9——nphi1 的"random 赢 J"模式在 nphi4 可行工作点不成立（1024 束失败区间内 random 中位 −37.5 仍低于物理 +328.0，6/8 种子，散布 −343..+1047）。**(3) 机制结论迁移**：跨 case Spearman(χ²/bin, ΔJ)=−0.689（n=19；nphi1 −0.694），"以密度拟合换权重平滑度"的权衡与欠定纹理机制网格无关；投影方向依旧大幅降 J 并大幅破坏密度（chi2 15.3/43.7）。**(4) full 解**：chi2/bin=0.455（2500 约束下密度不再可拟至 ~0）、N_eff=129、solve 223 s；4096 束 solve 约 50 s（约 4.5×），另计 grouping 约 3 s 与 score 约 10 s。诊断脚本 sweep 的 `solve_seconds` 字段含 scoring，比较用上述修正值。

净结论：分束加速的评估必须以 nphi4 为准——可行工作点约在 4096 束；该点物理分组 J 优于 random、solve 提速约 4.5×，密度代价 chi2/bin 0.455→1.36。是否进入阶段3/4由该工作点数字单独决定，nphi1 上的任何分束结论不再作为依据。

## 九、z 向减稀实验：full 路径提速与权重集中度（2026-09-16）

## 十、二维基 (Jz/Jtot, E)：分布审查与分束实验（2026-09-16）

§八之后的第三族二维基实验，动机来自 round-2 轨道不变量探索的 corner_actions 图：轨道平均垂直作用量份额 Jz/Jtot（φ 平均 Staeckel 作用量）与 E 接近秩不相关。问题：改用 (Jz/Jtot, E) 分位划分后，nphi4 可行工作点（4096 束）上的受限分束 J 是否优于现行 (λ_z,E) 基。

## 十一、第三不变量审计：变量问题还是束数问题（2026-09-16 设计，2026-09-17 运行完成）

§十之后的下一步方法问题：(f_z,E) 基在 nphi4 上仅 4096 束过密度门槛（约每已填束 1.4 条 active 轨道，等权约束几乎不绑定），而 1024 束对所有二维基失败。在引入第三分组变量之前，先无求解地审计：门槛失败归因于变量选择，还是束数本身。脚本 `scripts/audit_third_invariant.py`；本节先固定问题与检验设计，结果见下方补记。

三项检验（全部只读冻结产物：冻结库、round-2 不变量表、§十 bundles.npz、nphi4 run 配置）：

1. **束数曲线**：(f_z,E) 基在每轴 32/40/48/55/64 bins 上的失真与 full 解投影 chi2/bin——门槛可能在 1024 与 4096 束之间已经通过，无需第三变量。
2. **第三轴候选**（约 1024 总束）：λ_z（方位环流，与 f_z、E 均秩无关）与新的每轨道 xy 主轴角（轨道 xy 占据的取向，即 4 扇区网格实际看到的 phi 结构自由度）；两者同时审查 within-orbit 稳定性（split-half）。
3. **响应相似性 oracle**：对误差归一化响应列做普通 k-means（k=1024 与 2304），最小化等权分束所付的同一束内失真 D。oracle 的 D 与 full 权重投影 chi2 给出该束数下任何轨道分组可达的下界——若 oracle 不能显著低于二维/三维变量的 D，门槛束缚的是束数而非变量选择。

每分区报告：失真 D、已填束数、full 权重束均值投影 chi2/bin（不重解）与 2000 个同束列对方向余弦的中位数。产物目录 `.agent-local/benchmarks/third_invariant_audit/`。判读边界同§六/§七/§八：同一冻结库上的方法诊断，不外推生产替代或参数排序。

**结果（2026-09-17 运行，tycho，wall 124 s，全程无求解）**：运行代码为 `08ccc8c` 加两处审计脚本修复（random 对照补投影字段 `29b341e`、图例解包 `9f3521b`，延续分支 `codex/third-invariant-audit`；两次因脚本 bug 中断的运行数值表与最终运行逐位一致，全 seed=0）。设计矩阵 1040×5967（active 5967，与 §九/§十 一致）；64×64 投影 5.412 复现 §十审查值 5.41。

1. **束数曲线**：(f_z,E) 每轴 32/40/48/55/64——D 单调下降 0.949→0.624，full 权重投影 chi2/bin 单调下降 17.5→5.4，曲线平滑，1024 与 4096 之间不存在跳变；投影口径下任何束数都未接近 2.0 门槛（投影是悲观量，§十：4096 束重解把 5.41 收回到 1.61）。

4. **判读**：1024 束门槛失败主要是**变量问题**，不是束数问题——固定束数下不变量坐标划分留下约 2 倍的失真空间，而该束数下存在指标好得多的分组（oracle）；束数在 1024 处不构成硬约束。附带观察：响应列在每个势中本就要为密度求解计算，响应相似性聚类因此是逐势可行的分组机制候选（每次一个 k-means，本库约 1 分钟），且 oracle 束内 cos 0.53–0.59 直接显示其束内响应列真正同向（变量基 0.11–0.14、random 0.02）。但 oracle 束**重解后**是否过 2.0 门槛、J 代价多少，本审计不含重解、不回答；这是阶段3/4 进入判断的直接材料，不构成进入决定。
5. random 对照各束数 D 均略差于对应物理基（差 0.01–0.05），投影 chi2/bin 34–51 全部远超门槛——§七/§八"以密度拟合换权重平滑度"的机制再次一致。

**边界**：同 §六–§十——单冻结库、单次测量、无重解；投影 chi2 悲观，不能与 2.0 门槛直接比较。产物：tycho `.agent-local/benchmarks/third_invariant_audit/`（run3.log、summary.json、third_invariant_audit.png；run.log/run2.log 为两次因脚本报告/图 bug 中断的运行，数值表与 run3 逐位一致）。阶段3（生产锚点对齐）与阶段4（三势点排序 pilot）仍未进入。

**更正（2026-09-17 晚）**：§十二实现引入的小数组测试发现 `equal_weight_distortion`（`scripts/review_fz_energy_basis.py`）的 distortion 与 coherence 漏乘成员数 n_k，与其自身 docstring 及 k-means 目标定义不符（三个相同列成一束时真值 D=0，缺陷实现给 2/3）；已修正并回归测试（提交 `2f2ecc3`）。**上表全部 D 数值作废**，重算（run5，修正脚本与修正公式，wall 118.5 s）：(f_z,E) 束数曲线 D 为 0.750/0.667/0.570/0.495/0.416（1024/1600/2304/3025/4096 束）；第三轴候选 0.737–0.758；oracle k=1024 D=0.241、k=2304 D=0.081。修正后 oracle 对变量基的 D 优势约 3 倍（原"减半"低估了差距），"变量问题"的 D 证据增强而非削弱。投影 chi2、方向余弦与 k-means 分组本身均不受影响（k-means 一直最小化的就是正确定义的目标）；summary.json 与图已用修正公式重写。但 §十二的重解表明：D=0.241 的分组在 1024 束重解后仍不过门槛——束数与变量同时起约束作用。

**判读**：(1) **minibatch k-means 回答了 §12 的采纳障碍**——k-means++ 播种改 BLAS 点积形式 + Sculley minibatch 更新把分组从 74.6 s 降到 12.7 s（约 1/6），D 仅劣化 0.006（0.0877 对 0.0814），重解 chi2 1.214（oracle 1.162），端到端 38.5 s 成为已知最快过门槛工作点（对 (f_z,E)@4096 约 1.8×、对 oracle 约 2.6×）。(2) **纯变量网格的可行边界确定在 2304 与 4096 之间**——(f_z,E)@2304 以 2.147 差线失败，与 §11 投影曲线一致；PCA 响应网格确定性最便宜（1.0 s）但前两个主成分只解释 6.2% 方差，D=0.749 与变量网格同档，2.868 失败——线性降维不是替代聚类的方法。(3) **warm-start 5 步 Lloyd 把 D 从 0.570 压到 0.271 并贴线过门槛**（1.953，距门槛 0.047），机制上证明物理网格质心离 oracle 分组不远；但其束质量集中于 ~7.5 个有效束（最大束 36.0%），贴线通过依赖少数重束，单次测量下不足以作为工作点。(4) **权重集中度需要双层读法**——轨道级 N_eff（§10/§12 的报告口径）被等权回填抬高：oracle@2304 的 698 在束质量级只有 26.7（最大束 18.6%），反而比 (f_z,E)@4096（62.0 / 9.4%）更集中；minibatch@2304 束级 43.9 / 13.9% 是过门槛者中最分散的。"等权束结构上缓解权重集中"的 §12 结论只在轨道级成立，束级它是重分布而非缓解。(5) random 对照全部失败（2.42–4.14），成员数置换机制与前节一致。

**边界**：单冻结库、单种子、单次测量；minibatch 的 D 与 chi2 对 batch/rounds 参数的敏感性未扫；warm-start 贴线通过在单次测量下不能区分 1.95 与 2.0 的真实距离；全部计时为 tycho 顺序执行口径。阶段4 进入材料更新为：minibatch@2304（oracle 侧分组的实现候选）与 (f_z,E)@4096 进同一预注册 ΔJ 保真度协议。
